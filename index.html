How hard do you hit in Forever?

How the WoW Forever beta changes spell damage and healing compared with Classic. Read the breakdown, or open the calculator and enter your own spell power, +healing or attack power. Same rank, before talents, crit and buffs.

Forever cut base damage so gear carries it.

Mage and shadow priest spells need about 75 spell power to catch up with Classic. Warlock, shaman and balance druid need 250–700. Most heals need about 140 +healing.

How to read it

Fact check

All numbers checked against the sources on 23 Sep 2026.

Base values match

About 80 base values for mage, priest, warlock, druid and shaman match the ForeverChanges spellbooks.

Coefficients match

All 28 checked against 60.tools, e.g. Arcane Missiles 143% vs 120%, Bane of Doom 400% vs 100%.

Physical changes confirmed

Backstab +150 (was +225), Aimed Shot +166 (was +600), Raptor Strike +70 (was +140), Bloodthirst 35% AP + 48 (was 45%).

Players agree

Blizzard forum testers measured ~715 SP for Chain Lightning to break even; the data says 699.

Not DPS

Cast time, crit, mana, talents and rotation aren't included. A low number doesn't rank classes.

Beta data

Build 69977. The beta started 17 September, so values can change before launch.
